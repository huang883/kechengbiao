# 课间 Android App

五个入口：今天、周课表、待办、导入、设置。数据保存于应用私有目录的 SQLite，导入草稿与正式课程分开。

在项目根目录运行 `./tools/build_android.ps1`，完成静态检查、页面测试并输出 `output/android/campus-time-0.1.1.apk`。工具路径配置见 `tools/android_env.ps1`。完整领域及数据库回归执行 `./tools/verify.ps1`。

安装后选择原始学校 PDF，检查学期和课程，明确选择学校的周起始日；未排课条目需修正或主动排除。勾选确认后才保存正式课表，再在设置填写学校真实上课钟点。没有默认或推测的作息时间。

本地提醒安排未来 7 天，打开应用或修改日程时更新。系统省电可能延迟提醒。0.1.1 为本地测试签名构建；正式上架需配置自己的发布签名。设备测试状态以 `docs/ANDROID_QA.md` 为准。
