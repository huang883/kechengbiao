# 0.1.12：点击编辑与新建课程

- 周课表课程卡片固定白色文字，保留 WakeUp 参考色板及用户手动颜色。
- 点击周课表课程或今天的课程，直接打开编辑窗口。可修改课程名称、上课地点、星期、周次，并在「按节次」与「自定义钟点」之间切换。
- 名称修改应用于当前课表中同一课程的各条排课；时间、地点和周次只修改打开的那条排课。不会修改学校统一作息，也不会影响其他课表。
- 点击周课表空白处新建课程：默认所点星期和当前周；点在作息节次内时选中对应节次，否则按点击钟点预填。可自行选择更多周次。节假日停课仍生效。
- 课程编辑窗口可通过关闭按钮、系统返回或下滑退出；保存按钮固定底部。保存后刷新周课表、今日日程及提醒。
- 已有单节调课的来源排课可直接修改名称和地点。为避免已有调课来源失效，修改该来源排课时间/周次前需先撤销对应调课。自定义钟点课程直接编辑时间，不参与按节次拆分调课；目标节次发生调课时保留独立钟点课程，按实际时间展示并行安排。
- 数据库升级至 v5，只新增 course_schedule_times 存放每条排课的自定义起止钟点；保留旧课程、任务、作息、颜色及导入审计。

验证：49 项核心测试、24 项数据库测试通过，含 v1—v4 升级及关闭后重新读取；课程新建→点击编辑→改名/地点→08:12 自定义钟点→保存、白字、手机尺寸页面渲染检查通过。原有 14 项界面/通知回归测试通过。按此前用户要求跳过真机验证。
