# [BUG REPORT] IMP-001

ID：IMP-001

Severity：P1（导入主路径受阻）

Device：用户报告；此前 USB 枚举为 HONOR 90 / REA-AN00。当前 ADB 未连接，无法核实手机安装版本和屏幕状态。

Android Version：未知，未用规格猜测。

Page：PDF 导入预览。

Steps：选择真实学校课表 PDF → 预览提示确认周起始日 → 找不到对应确认按钮，无法导入。

Expected：提示附近有明确的选择与确认入口；保存后不再提示已解决的条件；其他阻断原因应准确指出。

Actual：0.1.0 的周起始下拉框位于四项学期字段之后，另需点击“保存学期信息”。更严重的是任何课程校验错误都会显示同一段“请确认周起始日”提示，即便该字段已经保存，仍可能误导用户反复寻找周起始确认入口。

Logs：无手机异常堆栈可用。修改前的 Widget 回归在“首屏应可点击确认周起始日按钮”处失败，命中 0 个按钮；现有代码分支证实错误提示未区分周起始、其他学期字段和未解决课程。

Root Cause：入口不明显、选择与保存分离；聚合错误提示与实际未完成项不对应。PDF 未声明周起始日是正常的待确认数据，不能用开学日期自动推断。

Affected Module：Import Preview / SemesterEditor；不涉及解析结果或 schema。

Recommended Fix（已实现）：顶部增加独立“确认周起始日”入口，星期一到星期日均可显式选择，点击“确认并保存”直接保存草稿字段。取消不写入、未知值不预选、保存不自动导入。预览末尾也提供未确认时的入口。课程和学期校验提示分开；课程卡片显示待处理提示。修订后最终导入勾选仍需重新确认。

Regression Risk：草稿版本变化、已有确认状态、课程排除及最终正式导入；保留既有 Repository 校验、revision 与事务，不迁移或清空数据库。

Test After Fix：真实 PDF 样本在 390×844 页面首屏可点击；取消保持 unclear；明确选星期日并保存后周起始错误消失，剩余未排课记录单独提示；明确排除该记录并最终确认后入库 22 条排课。星期日仅为测试输入，不代表学校真实约定。完整 Flutter 回归和截图检查结果见本轮交付记录。
