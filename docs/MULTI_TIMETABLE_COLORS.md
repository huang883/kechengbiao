# 0.1.10 — 默认课表、多课表与任意课程颜色

- 首次启动且本机尚无课表时，原子写入用户授权的「黄锐的课表」：22 条排课、14 门课程、2026-08-31 星期一起算、11 节作息及已确认的中秋/国庆/元旦当天停课。保留正常排课的大学英语（三），只排除用户指定的未排课「其他课程」记录。
- 覆盖升级不改写已有课表、调课、节假日、待办或颜色。
- 不同 PDF 导入为独立完整课表；同一 PDF 按文件指纹复用已有课表，避免重复。导入仍需预览确认；重复导入提示可打开相应课表。
- 周课表顶部提供课表选择及名称编辑。名称为 1—60 字符；选择持久化，今日日程及课程提醒跟随当前课表。待办保持全局。
- 设置 → 课程颜色 → 点击课程：支持 HSV 连续取色、3/6 位 HEX（可省略 #）、原有快捷色板、实时预览、取消与保存。每门课程独立保存，周课表与今天同步读取。浅色课卡自动使用深色文字。
- 不增加数据库版本：复用现有学期名称、课程颜色字段。

## 开源参考

参考 https://github.com/mchome/flutter_colorpicker 的 HSV 选色和弹窗确认交互（MIT 项目）。本版使用 Flutter HSVColor 与原生组件独立实现，没有复制第三方源码，也没有引入额外依赖。用户澄清后不再采用全课程统一颜色方案。
