# 0.1.13：调课直接编辑与不指定时间的待办

- 点击单节调入的课程，打开「编辑这次调课」。可以修改目标星期/周次、节次或自定义钟点、地点，不需要撤销调课；来源日期、节次以及移走/保留选项继续保留。
- 目标时间与地点作为此次调课的独立设置保存。来源排课时间、地点不被改写。课程名称仍作用于同一课程。
- 原排课也可直接修改时间/周次，已有调课的目标安排保留，不再要求先撤销。
- 自定义钟点按独立时间段显示，和同时段课程并列；按节次调整仍沿用原有覆盖规则。编辑调课列表中的旧节次表单会恢复按节次计时。
- 待办编辑新增「指定时间」开关：关闭后只选择日期，不要求开始/结束钟点，不发送定时提醒，不参与时间冲突计算。
- 不指定时间的待办出现在待办列表、今日独立区域和周课表「不指定时间的待办」区域。周课表只显示未完成项，支持点击编辑及直接勾选完成；保留已设置时间的待办行为。
- 数据库 v6 将待办起止时间改为可空，并新增 lesson_transfer_edits 存储调课目标覆盖设置。已有课程、任务、调课与原提醒设置保留。

验证：49 项核心测试、25 项存储测试（含旧库升级与重新打开）、12 项既有界面测试、5 项课程/待办/通知流程测试及手机尺寸渲染检查通过。新增验证覆盖不指定时间待办创建、显示、完成、转为定时/转回不定时，以及调课目标编辑、来源不变、来源仍可编辑、撤销后覆盖记录清理。沿用用户要求跳过真机验证。
