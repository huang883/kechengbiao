# 0.1.14：明确调课编辑范围

用户确认后的最终行为：点击已调入课程，默认选择「修改原排课」，保留调课的目标时间。编辑窗口顶部同时提供「只改这次调课」。

- 修改原排课：加载来源排课的星期、全部生效周次、地点和时间；保存不改写独立的调课目标时间。
- 只改这次调课：加载这次调课的目标星期、周次、地点和时间；保存不修改原排课。
- 切换范围时分别保留未保存的时间、地点及周次输入；课程名称属于同一门课程，两个范围共享名称。
- 不指定时间待办功能保留。数据库仍为 v6，无需新增数据迁移。

验证：两种范围保存、重开默认来源、切换时保留草稿、目标时间/地点不被来源修改覆盖、原周次保持、普通课程编辑、新建及不定时待办流程测试通过；静态检查与手机尺寸页面渲染通过。按此前要求跳过真机验证。
